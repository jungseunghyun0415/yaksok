# 약속

복용 알림 + AI 병용 주의 안내 (GitHub Actions 기반 자동화)

## 소개
약이나 영양제를 먹는 것을 자주 잊어버리고, 함께 먹으면 안 되는 약을
알기 어렵다는 문제에서 출발한 프로젝트입니다.
복용 중인 약과 복용 주기를 등록하면 정해진 시간에 알림을 보내 주고,
약 정보와 병용 주의가 필요한 약은 AI가 이해하기 쉬운 말로 설명해 줍니다.

## 주요 기능
- **복용 알림**: 등록한 약 이름·시간·기간에 맞춰 Discord로 알림 발송
- **약 정보 검색**: 약 데이터(CSV)에서 제품명·제조사·주성분 검색
- **병용금기 확인**: 병용금기 데이터(DUR)를 먼저 조회 (연동 진행 중)
- **AI 쉬운 설명**: 확인된 데이터를 Gemini API가 쉬운 한국어로 풀어서 안내
- **사진으로 약 찾기**: 약 포장지 사진에서 이름을 읽고, 약 데이터에서 다시 검색해 사용자가 확인
- **데스크톱 화면(GUI)**: 이름 입력, 캘린더, 복용 기간·횟수·시간 설정
- **자동 실행**: GitHub Actions 스케줄(cron)로 서버 없이 동작

## 동작 방식
약·복용 일정 등록(`data/medicines.json`) → GitHub Actions 30분마다 실행
→ 복용 시간 확인 → 약 데이터 조회 → AI 쉬운 설명 생성 → Discord 알림 발송

AI가 임의로 판단하지 않도록(환각 방지), 약 정보와 병용금기 여부는 데이터로 먼저 확인하고
AI는 확인된 내용을 쉬운 말로 설명하는 역할만 맡습니다.
사진 인식도 AI는 약 이름만 읽고, 정보는 약 데이터에서 찾은 뒤 사용자가 맞는지 확인합니다.

## 실행 방법
```
pip install -r requirements.txt
python src/main.py            # 내 컴퓨터: GUI 창이 열립니다 (gui/requirements.txt 설치 필요)
python src/main.py --notify   # 창 없이 알림만 처리 (GitHub Actions와 같은 동작)
```
테스트는 `TEST_MODE=true`로 시간과 상관없이 등록된 약을 모두 발송하고,
`DRY_RUN=true`를 같이 쓰면 실제로 보내지 않고 화면에만 출력합니다.

## 폴더 구조
```
.github/workflows/notify.yml   자동 실행 설정 (스케줄 + 수동 실행)
src/main.py                    통합 진입점 (알림 처리 / GUI 실행)
src/ai_analyzer.py             AI 설명 프롬프트 (김준우)
src/drug_db.py                 약 데이터 검색
src/schedule_store.py          복용 일정 읽기·저장
src/photo_identify.py          사진에서 약 이름 인식
src/settings_store.py          로컬 설정 저장
notification/                  Discord 알림 (로즈)
gui/                           데스크톱 화면
data/                          약 데이터, 병용금기 데이터, 복용 일정 (박채민)
yaksok/src/                    병용금기 프롬프트 (박채민)
```

## 진행 상황
| 항목 | 상태 |
|---|---|
| 약 데이터 정리 (CSV) | 완료 |
| AI 설명 프롬프트 | 완료 |
| Discord 알림 모듈 | 완료 |
| 통합 진입점 `main.py` (시간 판단 → AI 설명 → 알림) | 완료, 로컬 실행 확인 |
| GUI (캘린더·복용 설정·약 검색·사진) | 구현, 윈도우 환경 확인 중 |
| GitHub Actions 자동 실행 | 설정 완료, 통합 코드 기준 실제 알림 확인 예정 |
| 병용금기(DUR) 데이터 연동 | 진행 중 |
| 사진 인식 실제 테스트 (Gemini 호출) | 예정 |

## 향후 계획
- 병용금기 데이터(DUR)와 프롬프트를 알림 흐름에 연결
- 약 포장지 사진 인식으로 약 자동 등록
- 알림 채널 확장 및 복용 기록 관리

## 참고 사항
- API 키와 웹후크 주소는 GitHub Secrets에 보관하며, 코드나 레포에 올리지 않습니다.
- GitHub Actions의 cron은 지연될 수 있어 30분 단위로 확인합니다.
- ⚠️ 이 프로젝트의 안내는 의학적 조언이 아니며, 정확한 복용 방법은 약사·의사와 상담하세요.
