# 약속 

복용 알림 + AI 병용 주의 안내 (GitHub Actions 기반 자동화)

## 소개
약이나 영양제를 먹는 것을 자주 잊어버리고, 함께 먹으면 안 되는 약을
알기 어렵다는 문제에서 출발한 프로젝트입니다.
복용 중인 약과 복용 주기를 등록하면 정해진 시간에 알림을 보내 주고,
병용 주의가 필요한 약은 AI가 이해하기 쉬운 말로 설명해 줍니다.

## 주요 기능
- **복용 알림**: 등록한 약 이름·시간·주기에 맞춰 알림 발송 (Discord 등)
- **병용금기 확인**: 식약처 DUR 공공데이터 API로 병용금기 성분을 먼저 조회
- **AI 쉬운 설명**: 확인된 결과를 Gemini API가 쉬운 한국어로 풀어서 안내
- **자동 실행**: GitHub Actions 스케줄(cron)로 서버 없이 동작

## 동작 방식
약·복용주기 등록(JSON) → GitHub Actions 스케줄 실행 → 복용 시간 확인
→ DUR API 병용금기 조회 → AI 쉬운 설명 생성 → 알림 발송

AI가 임의로 판단하지 않도록(환각 방지), 병용금기 여부는 공공데이터로 먼저 확인하고
AI는 확인된 결과를 쉬운 말로 설명하는 역할만 맡습니다.

## 기술 스택
Python · GitHub Actions · 공공데이터 DUR API · Gemini API · Discord Webhook

## 참고 사항
- API 키는 GitHub Secrets에 보관합니다.
- GitHub Actions의 cron은 지연될 수 있어 30분 단위로 확인합니다.
- ⚠️ 이 프로젝트의 안내는 의학적 조언이 아니며, 정확한 복용 방법은 약사·의사와 상담하세요.
